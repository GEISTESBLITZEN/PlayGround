## Spore Genesis

A complete, single-page evolution survival game built with vanilla HTML, CSS and JavaScript. No build step is required.

You begin as a soft hatchling in a 6,400 × 6,400 procedurally generated world. Eat, drink, hunt, explore ten biomes, spend DNA on 30 genes, evolve through five stages, found a den once Nest Instinct is unlocked, build seven den modules, court a kindred, and breed heirs that inherit your mutations. The run ends with a proper Ascendant finale, but you can keep exploring afterward.

### Play

Serve the folder with any static file server and open `index.html`:

```bash
python3 -m http.server 3002
```

Then visit <http://localhost:3002>.

### Controls

| Action | Desktop | Touch |
| --- | --- | --- |
| Move | WASD / arrow keys | Virtual joystick |
| Sprint | Shift | `»` button |
| Bite | Space / F / click | Bite button |
| Interact / eat / drink | E | `E` button |
| Special ability | Q | `✦` button |
| Evolution | M | Evolve button |
| Den & craft | B | Den button |
| World map | Tab | Map button |
| Journal | J | Journal button |
| Pause | Esc / P | Pause button |

Progress saves automatically to `localStorage`. The game is responsive and includes safe-area-aware mobile controls.

### Systems

- 30 permanent gene upgrades across body, senses, metabolism, social and exotic branches, with five evolution stages and stage-gated unlocks.
- Living ecosystem with prey, predators, a wandering boss, weather, day/night lighting, fireflies, storms and a golden rare creature.
- Gathering, crafting, den building, resting, gardens, shrines, lookouts and palisades.
- Courtship and generational breeding: heirs become companions, inherit and upgrade genes, and add a permanent legacy bonus.
- Eleven objectives, eleven achievements, a field journal, a fog-of-war world map, minimap, sound effects and particle feedback.
